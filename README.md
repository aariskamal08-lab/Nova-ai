# 🤖 Nova AI - My Personal AI Assistant

Nova AI is an independent, student-built AI assistant created by a 16-year-old developer. It is designed to provide smart, multilingual, and context-aware responses to help with daily tasks, coding, and learning.

## ✨ Key Features
- **Multi-language Support:** Speaks English, Hindi, and Hinglish.
- **Smart Responses:** Powered by the Gemini API for accurate and helpful answers.
- **Clean UI:** A fully responsive, mobile-friendly dark mode interface.

## 🛠️ Tech Stack
- HTML, CSS, JavaScript (Frontend)
- Gemini API (AI Engine)
- GitHub (Hosting)
